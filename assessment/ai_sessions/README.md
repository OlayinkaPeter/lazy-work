# AI sessions

We use AI tools every day and expect you to as well. If you used any (Claude Code, Cursor,
Copilot, ChatGPT, ...) while working on this take-home, put the transcripts or exports here.

- Any format is fine: exported markdown, JSON logs, screenshots, or a short summary per session.
- Redact secrets, tokens and anything personal.
- A line or two on what worked and what you had to correct is more useful to us than volume.

We are interested in how you work with these tools: what you delegate, how you check the
output, and where you override it. Using them will not count against you.
